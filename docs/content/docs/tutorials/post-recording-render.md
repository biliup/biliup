## 适合本地素材录制的配置

在 **直播管理 → 对应直播间 → 配置覆写** 的「下载设置」里点击 **使用本地素材录制预设**，保存后会为这个直播间设置：

| 设置 | 值 | 作用 |
| --- | --- | --- |
| 下载器 | `mesio` | 将视频分段写入本地，适合后续回看和切片 |
| 上传器 | `Noop` | 不投稿，但仍会执行必要的本地处理 |
| 碎片过滤 | `0` | 保留短分段，避免切片素材被大小阈值过滤 |
| 后处理 | 空列表 | 不执行默认的 `rm`，保留视频和弹幕文件 |
| 录制阶段遮挡 | 关闭 | 将遮挡留到工作台编辑，避免反复转码 |

这个按钮只修改当前直播间的覆写配置；已经录制的文件不会被删除或重新处理。`sync-downloader` 是边录边传模式，不适合这条本地工作流，预设会明确选择 `mesio`。

## 在工作台编辑和合成

下播后打开 **剪辑台 → 直播场次 → 回看**，进入 **画面与弹幕** 面板。播放器显示纯净画面，原始视频和 XML 会一直保留。

### 遮挡图层

- 添加马赛克、模糊、纯色或 PNG/JPEG 图片图层。
- 勾选「画面拖拽编辑」后，在播放器上拖动图层；八个控制柄可以缩放图片或区域。
- 默认锁定图片宽高比，也可以取消锁定。左侧、顶部、宽度、高度和不透明度可以用数字精确调整。
- 图层支持调整顺序。每个图层可以全程生效，也可以添加多个场次时间区间；区间终点不包含在效果内。
- 图片以资源 ID 保存，配置和合成任务不会接受浏览器直接提交的服务器路径。

### 弹幕

打开「压制弹幕」后，工作台使用与导出相同的 ASS 生成流程预览。可以调整字体、字号、透明度、描边、滚动速度、显示范围、密度、场次偏移和分段偏移补偿。正偏移表示弹幕延后。

## 导出

「合成导出选段」会把精确剪辑、遮挡、图片叠加和弹幕压制放进同一次 FFmpeg 编码。多个源分段最后用无重编码方式拼接，完成后得到可播放的 MP4；「导出整场 MP4」只在场次结束后可用。

第一次导出前，请在 **空间配置** 确认 FFmpeg 可用，并检查 `libass`、`libx264` 和中文字体。工具页面会显示检测结果。合成任务会显示排队、进度、失败和重试状态；取消或失败不会删除原视频、XML 或图片资源。

成品可以在任务列表中播放或下载，再交给你的切片整理和投稿流程。biliup 不会因为合成完成自动投稿；投稿仍由切片工作台和现有投稿流程决定。

## 时间和原片保护

视频、XML、遮挡区间和弹幕偏移使用同一场次时间轴。断流空档不会写入成品，空档中的弹幕会被丢弃；跨越空档的滚动弹幕会在边界结束。片段入点前仍在滚动的弹幕会保留必要的前导时间，避免切片开头重新出现。

合成任务使用创建时的配置和图片快照。之后修改工作台配置只影响新任务；原始视频、XML、工作台索引和旧成品仍可继续使用。

## 性能和故障处理

合成会重新编码视频，CPU 和临时磁盘占用会随分辨率、帧率和时长增加。默认使用 CPU 编码；长场次可以先导出需要的切片，再按需导出整场。

缺失或损坏的 XML 会让启用弹幕的任务失败，并指出问题分段。关闭弹幕后可以重新导出；合法的空 XML 可以正常完成没有弹幕的成品。若任务失败，先检查 FFmpeg、编码器、字体、磁盘空间和源分段完整性，再使用任务列表中的「重试原配置」。
